# Background music

Put 1–3 calm instrumental tracks from **YouTube Studio → Audio Library** here
(filter: *No attribution required*; ambient / lo-fi / calm). Downloads are gitignored.

`tools/music.py` uses the first file by name (rename to `01_….mp3` to choose).
Loops get a 4 s crossfade and the music ducks under the narration.
If a track says *attribution required*, add its credit line to the episode's youtube.md.
